# Security Policy

OptionSentinel handles brokerage credentials and can submit real orders, so security reports are taken seriously.

Report vulnerabilities through GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing credentials, tokens, account hashes, portfolio data, or exploit details. If private reporting is unavailable, open a minimal issue requesting a private contact channel without including sensitive details.

Only the latest version on the `main` branch is currently supported. Never send real credentials or tokens as part of a report or reproduction.
